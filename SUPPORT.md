# Support

- Documentation: [guard-core.com](https://guard-core.com), and each library's docs site linked from its README.
- Questions about a library: GitHub Discussions in that library's repository.
- Chat: [Discord](https://discord.gg/ZW7ZJbjMkK), #help for questions, #releases for new versions.
- Bugs and feature requests: the issues of the library concerned; for the hosted app, [saas-issues](https://github.com/Guard-Core/saas-issues).
- Security reports: [SECURITY.md](SECURITY.md), never a public issue.
